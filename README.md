# கல்வி.AI

> AI Literacy Platform for Government Schools in Tamil Nadu
> A Daruma™ Original

## What is this?

Kalvi.AI gives every government school a ready-to-run AI literacy
programme — so that by the time a 12-year-old in Dharmapuri finishes
Class 8, they can pick up any AI tool and use it independently, in Tamil.

## Quick Start

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your keys
3. Run schema: paste `packages/db/schema.sql` into Supabase SQL editor
4. Start mobile: `npm run mobile`
5. Start web: `npm run web`
